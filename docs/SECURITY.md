# Безопасность и пределы прототипа

## Реализованные меры

- Конфигурация по умолчанию использует локальные модели и локальное хранение исходников. Внешние API генерации не настроены. Адрес Ollama задаётся конфигурацией; перед размещением нужно проверить, что он указывает на согласованный локальный сервис.
- Сессионные cookie HttpOnly и SameSite, срок 8 часов, хеш токена в БД.
- Пароли PBKDF2-HMAC-SHA256 с индивидуальной солью. При первом недемонстрационном запуске обязателен пароль администратора не короче 12 символов.
- Роли сотрудника, куратора, администратора. Изменение источников доступно куратору, журнал доступен администратору. Личные диалоги и черновики проверяются по владельцу.
- ACL до поиска и при скачивании. Архивные/черновые версии не становятся автоматически активными.
- Проверка Origin и Host, защитные HTTP-заголовки, ограничения частоты входа и тяжёлых запросов.
- Ограничение загрузки 25 МиБ и входящего потока независимо от Content-Length: до 26 МиБ на multipart, до 1 МиБ на прочие запросы. Проверка формата, размера распакованного DOCX и сложности PDF. Ошибки валидации не отражают введенные пароли/полный запрос.
- DOCX: запрет макросов, внешних связей (включая гиперссылки), встроенных объектов, ActiveX, подключаемых шаблонов, DTD/ENTITY и полей DDE/INCLUDETEXT и аналогичных. PDF: запрет скриптов, автоматических действий и вложений. Имя загрузки не используется как путь. Это строгий профиль прототипа: для загрузки документа со ссылками потребуется копия без внешних связей.
- Аудит действий без сохранения полного текста запроса в журнале. Исходный вопрос остаётся только в личной истории диалога.
- LLM получает документы как недоверенные данные и не имеет инструментов выполнения команд. Ссылки проверяются по найденным фрагментам; это снижает риски prompt injection, но не гарантирует смысловую корректность. Генератор не создает действительную электронную подпись.
- Генерация ответа, заполнение полей, смысловой поиск и индексатор используют общий лимит из двух одновременно выполняемых задач в одном процессе API. При занятых слотах интерактивный запрос получает сообщение о занятости, а индексатор ждёт освобождения слота. Это ограничение конкурентности, не распределённая очередь. Активации источников сериализованы; при несовпадении версии источника и схемы шаблон скрывается до восстановления согласованности.

## Учебный режим

`DEMO_MODE=1` разрешает выбрать демонстрационную роль без пароля. Это сделано для жюри и локального тестирования. Такой режим не является защитой от посетителя, который намеренно выбирает администратора. Для каждой роли используется один общий учебный аккаунт: посетители с одинаковой ролью видят его диалоги и проекты. По умолчанию нативный сервер и Docker-порт привязаны к loopback.

Для доступа из сети отключите демо, настройте HTTPS и корпоративную аутентификацию. Пароль первого администратора берётся из `ADMIN_PASSWORD`. В локальном демо случайный пароль обычного администратора сохраняется в игнорируемом `data/runtime/admin-password.txt`.

После отключения демо ранее выданные демонстрационные сессии больше не дают доступ. Изменение `ADMIN_PASSWORD` не перезаписывает учетную запись, уже созданную в БД; используйте локальную команду смены пароля из `docs/ACCOUNTS.md`.

## Что ещё требуется для промышленной эксплуатации

Корпоративный SSO/OIDC и централизованное управление жизненным циклом учётных записей, независимая проверка моделей, DLP/антивирус, шифрование дисков и резервных копий, серверный регламент хранения, нагрузочные испытания, защита периметра, централизованный журнал и управление инцидентами. Локальное создание и отключение пользователей, а также смена пароля уже доступны через CLI, описанный в `docs/ACCOUNTS.md`; корпоративной интеграции пока нет. Прототип не заявляется сертифицированным средством защиты информации.

Проверка существования цитаты предотвращает ссылку на несуществующий фрагмент, но не доказывает логическую корректность вывода. Для ответственных решений сохраняется экспертная проверка. Полный набор регламентов, полномочий подписантов и номенклатура дел в материалах кейса отсутствуют.
