# Покрытие критериев кейса

Соответствие требованиям — описание реализованного объема, а не прогноз оценок жюри. В исходном кейсе пять критериев по 5 баллов.

| Критерий | Что реализовано | Как показать |
|---|---|---|
| Качество ответов и работа с источниками | Поиск по русским словоформам и локальным эмбеддингам, точные цитаты, пункт и физическая страница PDF, неизменяемая версия источника, уточнения и отказ при нехватке сведений | Вопрос о регистрации входящего документа → п. 5.6 → раскрыть цитату и оригинал; вопрос о зарплате → отсутствие оснований |
| Пользовательские сценарии | История диалога, уточнение в контексте, поиск, подготовка проекта, отдельный расчет маршрута, проверка файла или текста | В одном сеансе пройти вопрос → модуль → заполнение → DOCX; затем проверить ошибочный текст |
| Модули документов | Семь исходных модулей, формы по их переменным, извлечение сообщенных значений локальной LLM, обязательные поля и условия, Word на основе исходных файлов | Заполнить рабочую группу, посмотреть предупреждения, скачать DOCX; куратор загружает новый шаблон с явными {{полями}} |
| Техническая реализуемость и потенциал внедрения | React/TypeScript + FastAPI + SQLite + Ollama; локальный запуск и Docker; роли, проверка доступа до поиска, личные черновики, журнал действий, версии и активация | Переключить демонстрационную роль; показать недоступные сотруднику операции, дату редакции, версии, API и воспроизводимые тесты |
| Выступление и аргументация | Презентация из 5 слайдов, сценарий на 3 минуты, видеообзор реальных экранов на 117 секунд, подготовленные примеры, архитектура, объяснение поиска и границ | docs/DEMO.md, итоговые файлы в output/ и локальное приложение; внешний адрес для тестирования пока не подготовлен |

## Статус обязательных артефактов

Исходное ТЗ, стр. 7, требует работающий прототип, описание архитектуры и стека, пользовательские сценарии, схему работы с базой знаний, описание поиска и ответов, интерфейс, видеодемонстрацию и ссылку для тестирования.

Код прототипа, отдельный веб-интерфейс, инструкции запуска и технические описания входят в комплект. В `output/` находятся редактируемая презентация из 5 слайдов и её растровая PDF-копия. Ролик длится 117 секунд и показывает реальные экраны приложения с пояснениями, без звука. Это монтаж экранов, а не непрерывная запись действий.

Ссылка `http://127.0.0.1:8765` работает только на компьютере с сервером. Требование предоставить URL для самостоятельного тестирования жюри пока не закрыто: нужен доступный экспертам экземпляр в согласованном сетевом контуре.

## Дополнительные возможности

- Проверка загруженного DOCX/PDF/TXT и вставленного текста с основаниями замечаний.
- Объяснение участников маршрута по совокупности строк матрицы и компетенциям.
- Загрузка редакции в черновик, сравнение текстов и явная активация.
- Выбор даты применения при ответе; обычный режим явно использует активную учебную редакцию.
- После обновления шаблона старый черновик требует повторного сохранения и проверки.
- При недоступной модели остаются извлеченные положения источников; интерфейс показывает режим.

## Ограничения, которые надо назвать честно

Показатели релевантности поиска не являются вероятностью правильного ответа. Проверка существования цитат не доказывает смысловую полноту ответа. Динамические шаблоны требуют явных маркеров полей и проверки куратора. Правила визирования реализованы кодом из предоставленной матрицы; произвольная новая матрица не переписывает автоматически этот код. Загруженные инструкции попадают в поиск, а изменение автоматических проверок требует обновления правил и тестов.

Работа с учебной базой не подтверждает юридическую силу документов. Проверка прототипа не заменяет подпись, экспертизу, корпоративный SSO, DLP и антивирусный шлюз. Публичного адреса нет; локальный запуск и видеоролик не подтверждают возможность внешнего доступа.
