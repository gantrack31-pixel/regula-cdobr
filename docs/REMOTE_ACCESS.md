# Доступ с телефона из другой сети

Локальный сайт остается на http://127.0.0.1:8765. Этот адрес не открывается с телефона.

Подготовлен отдельный защищенный экземпляр на loopback-порту 8767: `DEMO_MODE=0`, парольный вход, Secure/HttpOnly/SameSite cookie, точный разрешенный внешний hostname. Локальное демо на 8765 не публикуется. Модель и данные остаются на этом компьютере; HTTPS-провайдер туннеля обрабатывает проходящий через него трафик.

## Фактический результат 24.10.2026

Рабочей внешней ссылки пока **нет**. Cloudflare выдал имя, но не установил соединение с edge: TLS EOF, проверки TCP/UDP 7844 завершились ошибкой, внешний запрос получил HTTP 530/1033. Независимая попытка localhost.run завершилась тайм-аутом SSH. Настройки DNS, маршрутизации, роутера и межсетевого экрана не менялись.

Оба соединения остановлены, порт 8767 закрыт; основной сайт на 8765 отвечает HTTP 200. Не следует распространять имя из старого `tmp/remote-access/state.json` как действующую ссылку.

## Подготовленный запуск Cloudflare при доступности сети

```powershell
.\.venv\Scripts\python.exe scripts/start_remote.py
```

Скрипт получает официальный cloudflared, сверяет SHA-256 с GitHub-релизом, запускает временный туннель и отдельный сервер. Перед выдачей результата проверяет соединение, внешний HTTPS, запрет анонимного доступа, запрет демовхода, обычную авторизацию и защищенные cookie. Если соединение или проверки не прошли, останавливает свои процессы.

При первом запуске создан отдельный аккаунт владельца `remote-owner`. Его случайный пароль хранится только в `data/runtime/remote-access-credentials.json`; файл исключен из Git и релизного ZIP. Не публикуйте его. Доступ администратора позволяет менять базу знаний.

Остановка:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop_remote.ps1
```

Скрипт проверяет процессы перед остановкой и не трогает порт 8765. После повторного запуска адрес временного туннеля меняется. Компьютер должен оставаться включенным.

Альтернативный следующий шаг — подключить принадлежащий владельцу аккаунт ngrok или развернуть приложение на его сервере. Пароль аккаунта и токен сервиса вводятся локально, не в переписке. Постоянный адрес для жюри требует отдельно проверенного размещения.

Документация: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/), [localhost.run](https://localhost.run/docs/).
